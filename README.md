---

## 🔧 1. 环境配置

项目使用 Conda 管理环境，并提供 `environment.yml` 用于快速复现。

### 📥 1.1 克隆仓库

```bash
git clone https://github.com/Luer211/DataAnalysis_Learning.git
cd DataAnalysis_Learning
```

### 🧪 1.2 使用 environment.yml 创建环境

```bash
conda env create -f environment.yml
conda activate MathModel
```

---

## 📚 2. 项目简要说明

### 🔥 **「大纲总览」文件夹（必看）**  
这里放着 **7 个 Notebook 的学习思维导图** 🧠✨，能让你在 30 秒内了解整套学习路线，非常适合先快速浏览整体框架！

### 📁 Notebook 内容索引

* 📂 `data`：项目练习所需的数据  
* 📘 `1.numpy学习.ipynb`：NumPy 基础与数组操作  
* 📙 `2.series学习.ipynb`：Pandas Series 基础  
* 📗 `3.DataFrame学习.ipynb`：Pandas DataFrame 数据结构与常见处理  
* 🧹 `4.数据分析.ipynb`：数据清洗与描述性统计  
* 📊 `5.matplotlib学习.ipynb`：基础绘图与可视化示例  
* 🎨 `6.seaborn学习.ipynb`：统计可视化示例  
* 🏡 `7.房地产市场分析.ipynb`：综合房地产数据分析案例
